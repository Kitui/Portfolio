02

Project Overview

FlowOps is an event-driven cloud data platform that captures, processes and analyses GitHub activity to provide visibility into engineering workflows.

Authenticated webhook events are published to Pub/Sub, transformed with Dataflow and stored in BigQuery for operational analysis.

The system is built around managed Google Cloud services to provide scalable and low-maintenance event processing.

04

The Problem

  • Limited real-time visibility into delivery activity.
  • Manual reporting was slow and inconsistent.
  • No central view of event processing health.
  • Bottlenecks were difficult to identify quickly.
05

The Solution

  • Secure webhook ingestion through Cloud Run.
  • Event streaming with Pub/Sub and Dataflow.
  • Centralised analytical storage in BigQuery.
  • Operational monitoring and reporting.

  • End-to-end configuration, deployment and testing.
