Project Overview

RoadSafe Lakehouse is an end-to-end data engineering solution that consolidates accident records into a unified and governed analytical platform.

The platform uses a medallion architecture on Databricks with Delta Lake and Unity Catalog to establish data quality, traceability, governance and secure access.

Curated datasets and semantic business views are then published to Google BigQuery for downstream reporting, dashboarding and analytical consumption.

The Problem

  • Data distributed across inconsistent sources and formats.
  • Duplicates, missing values and unreliable data quality.
  • No consistent analytical source of truth.
  • Manual reporting with limited governance and trust.

The Solution

  • Centralised lakehouse using medallion architecture.
  • Automated data quality validation and monitoring.
  • Curated analytical datasets and semantic models.
  • BigQuery publishing for downstream analytics.

What I Personally Built

  • End-to-end ingestion pipeline using PySpark.
  • Data validation rules and quality controls.
  • Bronze, Silver and Gold transformations.
  • Unity Catalog governance and access controls.
  • Workflow orchestration using Databricks Jobs.
  • Curated BigQuery publishing workflows.
