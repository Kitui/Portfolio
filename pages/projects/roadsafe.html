Project Overview

RoadSafe Lakehouse is an end-to-end cloud data engineering platform designed to consolidate and govern large-scale accident records.

The solution uses Databricks, Delta Lake and PySpark to ingest, validate, transform and curate data through a structured medallion architecture.

Unity Catalog provides governance and controlled access, while curated datasets and semantic views support reporting through BigQuery and Databricks AI/BI.

04

The Problem

  • Accident data was distributed across inconsistent records.
  • Missing values and duplicates reduced analytical trust.
  • Manual reporting lacked repeatability and governance.
  • No unified source supported consistent safety analysis.
  • Operational monitoring and lineage were limited.
05

The Solution

  • Centralised ingestion into a governed Delta Lake platform.
  • Automated schema and data-quality validation.
  • Bronze, Silver, Gold and Semantic transformations.
  • Unity Catalog governance and controlled data access.
  • BigQuery publishing for analytical consumption.
