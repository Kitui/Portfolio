# Paul John Kitui Portfolio

A responsive personal portfolio focused on cloud data engineering, real-time streaming, applied AI and technical delivery.

## Current implementation

- Responsive navigation
- Dark and light themes
- Hero section
- About section
- Capability cards
- Scroll reveal animations
- GitHub Pages-ready structure

## Run locally

Open `index.html` directly in a browser, or use the VS Code Live Server extension.

## Before publishing

1. Add the latest résumé to:
   `assets/documents/paul-john-kitui-resume.pdf`
2. Replace the placeholder LinkedIn URL in `index.html`.
3. Confirm the GitHub profile URL.
4. Add project images and project case-study pages.

## Deployment

This project can be deployed directly through GitHub Pages from the repository's `main` branch.
